# Automated preprocessing

    python -m pip install -r pre-processing/requirements.txt
    python pre-processing/run_pipeline.py --epochs 180
    python pre-processing/verify_outputs.py

Run from the repository/project root.

| Script | Responsibility |
| --- | --- |
| build_dataset.py | Read three raw sources; create temporary join tables; build one master CSV |
| internal/merge_seasonal.py | Internal district-year-season join and weather aggregation |
| preprocess_master.py | Train-only imputation/scaling/encoding; conventional training CSVs |
| denoising_autoencoder.py | DAE fitting, validation checkpoint selection, latent exports and plots |
| run_pipeline.py | Run every stage and put each output in the correct folder |
| verify_outputs.py | Check rows/splits/targets/finite predictors and safe input-column selection |
| make_figures.py | Create coverage, yield, time-trend and correlation plots |

Crop_Preprocessing.ipynb is the maintained Colab notebook with full visible code,
including the exact source-selection/merge modules and standard/DAE methods
shown in the dataset presentation. It writes the displayed modules into the
Colab checkout before execution and validates the output feature schemas.
Both representations retain the same labels, rows and chronological partitions.
It includes saved output tables and all seven actual figures. Open it from the repository's
Colab link; the old notebook used the previous flat dataset layout.

artifacts/ stores fitted preprocessing only:
standard_preprocessor.pkl, standard_manifest.json, denoising_autoencoder.pt.
The checkpoint contains the numeric/categorical transforms and DAE weights.
At application inference, load the saved transforms rather than refitting.

These pickle/PyTorch artifacts were generated by this project. Load saved model
objects only from a trusted project copy. Versioned requirements record the
runtime used for this preprocessing run.

Training corruption: Gaussian noise standard deviation 0.05 on standardized
inputs. Encoder 21 -> 64 -> 32 -> 8; mirrored decoder; AdamW, MSE, clipping,
GELU, batch normalization and dropout. Validation chooses the best checkpoint;
test data does not guide training or selection.
